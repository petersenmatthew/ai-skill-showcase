## Sports ball type predictor w/ CNN 

### Summary
Complete pipeline for classifying images of sports balls:
    Training a CNN -> evaluating -> visualizing predictions
- Dataset from **Kaggle** containing 15 different types of sports balls
- Built a  **CNN** with two convolutional + pooling layers to extract features
- Achieved **43.55%** Accuracy with 10 Epochs
- Visual of results through a **confusion matrix model**

Built with **Pytorch** as the deep learning framework & **Matplotlib** for data visualization.
